# SnyX Dotfiles

Dotfiles de alto desempenho para **Arch / CachyOS** configurados e otimizados para o processador **AMD Ryzen 9 9950X (Zen 5 / x86-64-v4)**.

## 🚀 Arquitetura

- **Compositor:** [Hyprland](https://hypr.land) (Modular em Lua)
- **Desktop Shell:** [Noctalia](https://github.com/noctalia-dev/noctalia) (Shell unificada C++/Wayland)
- **Terminal:** [Kitty](https://sw.kovidgoyal.net/kitty/) (Aceleração direta na GPU)
- **Shell:** Fish
- **Gerenciador de Arquivos:** Thunar
- **Monitor:** 1920x1080 @ 144Hz (DP-1)
- **Assets & Utilitários:** Inspirados e importados do [JaKooLit / KooLDots](https://github.com/LinuxBeginnings/Hyprland-Dots)

## 📦 Instalação / Restauração

Para aplicar os symlinks em qualquer máquina ou reinstalação:

```bash
cd ~/dotfiles
./install.sh
```
